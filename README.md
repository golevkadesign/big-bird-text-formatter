# Big Bird Text Formatter | 大鸟文本格式化插件

## Description | 插件介绍

**Big Bird Text Formatter** is a Figma plugin designed to streamline the process of text formatting for multilingual content. It allows users to easily apply text styles to Chinese and English texts separately, ensuring a consistent and efficient design workflow. The plugin also provides one-click optimization for mixed-language text formatting, making it perfect for designers working with bilingual content.

**大鸟文本格式化插件**是一个为多语言内容设计的 Figma 插件。用户可以分别为中文和英文文本应用文本样式，从而简化文本格式化流程，确保设计工作流的一致性和高效性。插件还提供了中英文混排文本的一键优化功能，是处理双语内容的设计师的理想工具。

## Features | 功能特点

### Basic Features | 基础功能
- **Enhanced Text Styling**: Apply font, weight, size, line height, and spacing settings specifically for Chinese and English texts.
- **Tab-based Interface**: Quickly switch between Chinese and English panels using a clear tab-based interface.
- **Support for Mixed State Detection**: Automatically detects mixed attributes when multiple text nodes are selected.
- **Streamlined UI**: Designed with a clean and intuitive interface following Tailwind aesthetics.

- **增强的文本样式调整**：针对中文和英文文本，单独应用字体、字重、字号、行高和间距设置。
- **基于标签的界面**：通过清晰的标签界面快速切换中文和英文面板。
- **支持混合状态检测**：在选择多个文本节点时，自动检测混合属性。
- **简洁的用户界面**：遵循 Tailwind 风格设计的清晰直观界面。

### New Features (v1.4.0) | 新功能
- **One-Click Format Optimization**: Automatically adjusts spacing, punctuation, and typography for mixed-language text.
- **Smart Language Detection**: Identifies and applies appropriate formatting rules based on text content.
- **Batch Processing**: Process multiple text layers simultaneously.
- **Intelligent Line Height**: Automatically calculates optimal line height based on font size.

- **一键格式优化**：自动调整中英文混排文本的间距、标点和排版。
- **智能语言检测**：识别文本内容并应用相应的格式化规则。
- **批量处理**：同时处理多个文本图层。
- **智能行高**：根据字号自动计算最佳行高。

## How to Use | 使用方法

### Basic Style Application | 基础样式应用
1. Select text layers in Figma
2. Open the plugin
3. Switch between Chinese/English tabs
4. Adjust text properties
5. Click "Apply" to update styles

1. 选择 Figma 中的文本图层
2. 打开插件
3. 切换中文/英文标签页
4. 调整文本属性
5. 点击"应用"更新样式

### Quick Format Optimization | 快速格式优化
1. Select text layers or frames
2. Switch to "Quick Actions" tab
3. Click "One-Click Optimize"
4. Done! All text formatting will be automatically optimized

1. 选择文本图层或画板
2. 切换到"Quick Actions"标签页
3. 点击"一键优化"
4. 完成！文本格式将自动优化

## Formatting Rules | 格式化规则

The plugin applies the following rules during optimization:

| Rule | Description |
|------|-------------|
| Spacing | Adds spaces between Chinese/English and numbers |
| Punctuation | Converts between full/half-width based on context |
| Typography | Standardizes quotes, ellipsis and dashes |
| Layout | Optimizes line height based on font size |

插件在优化时应用以下规则：

| 规则 | 说明 |
|------|------|
| 间距 | 在中英文和数字之间添加空格 |
| 标点 | 根据上下文转换全角/半角标点 |
| 排版 | 规范化引号、省略号和破折号 |
| 布局 | 根据字号优化行高 |
