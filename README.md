# Big Bird Text Formatter | 大鸟文本格式化插件

## Description | 插件介绍

**Big Bird Text Formatter** is a Figma plugin designed to streamline the process of text formatting for multilingual content. It allows users to easily apply text styles to Chinese and English texts separately, ensuring a consistent and efficient design workflow. 

**大鸟文本格式化插件**是一个为多语言内容设计的 Figma 插件。用户可以分别为中文和英文文本应用文本样式，从而简化文本格式化流程，确保设计工作流的一致性和高效性。

## Features | 功能特点

- **Enhanced Text Styling**: Apply font, weight, size, line height, and spacing settings specifically for Chinese and English texts.
- **Tab-based Interface**: Quickly switch between Chinese and English panels using a clear tab-based interface, enabling focused text adjustments.
- **Support for Mixed State Detection**: Automatically detects mixed attributes when multiple text nodes are selected.
- **Streamlined UI**: Designed with a clean and intuitive interface following Tailwind aesthetics.

- **增强的文本样式调整**：针对中文和英文文本，单独应用字体、字重、字号、行高和间距设置。
- **基于标签的界面**：通过清晰的标签界面快速切换中文和英文面板，专注于文本调整。
- **支持混合状态检测**：在选择多个文本节点时，自动检测混合属性。
- **简洁的用户界面**：遵循 Tailwind 风格设计的清晰直观界面。

## How to Use | 使用方法

1. **Select the Text**: Choose one or multiple text frames within Figma that you want to style.
2. **Open the Plugin**: Launch the plugin from the Figma plugin menu.
3. **Tab Switch**: Use the tab at the top to switch between Chinese and English panels.
4. **Adjust Text Styles**: Modify text properties such as font, size, and spacing as needed.
5. **Apply Styles**: Click the "Apply" button to update the selected text frames.

1. **选择文本**：在 Figma 中选择一个或多个需要调整样式的文本框。
2. **打开插件**：从 Figma 插件菜单中启动插件。
3. **标签切换**：使用顶部标签在中文和英文面板之间切换。
4. **调整文本样式**：根据需要修改字体、字号、间距等文本属性。
5. **应用样式**：点击“应用”按钮以更新所选文本框的样式。
